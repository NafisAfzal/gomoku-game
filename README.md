# Gomoku Game

A simple two-player Gomoku game made with HTML, CSS, and JavaScript.
Just for fun and casual play.

## About

This is a small browser game for two local players. Black and White
take turns placing stones on the board. The first player to get five
stones in a row wins. There is no AI and no online play. You play it
together on one screen.

## Features

- 9x9 board
- 11x11 board
- 13x13 board
- 15x15 board
- 17x17 board
- 19x19 board
- 5-in-a-row win condition
- Two-player local gameplay
- Move history
- Undo
- Win detection
- Draw detection
- Responsive layout
- Short win celebration

## How It Works

The board is stored in JavaScript. Players take turns placing Black
and White stones. After each move, the game checks the four possible
directions for five consecutive stones. The UI is updated directly in
the browser using HTML, CSS, and JavaScript.

## Run Locally

1. Download or clone the repository.
2. Open index.html in a browser.
3. Choose a board size.
4. Click New Match.
5. Start playing.

No build step is needed.
